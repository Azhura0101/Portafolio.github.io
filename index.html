Sobre Mí

Soy desarrollador web Python y Flask en Colombia, especializado en construir sistemas de gestión empresarial, APIs REST y aplicaciones web completas. Trabajo con clientes reales desde 2024.

Mi stack es Python + Flask en backend, SQLAlchemy como ORM, PostgreSQL en bases de datos y Bootstrap/CSS en el frontend. Entiendo la arquitectura completa: desde la base de datos hasta la interfaz del usuario.

Me mueve la intersección entre usabilidad, performance y diseño. Creo que el buen software debe ser rápido, confiable y, sobre todo, útil para el usuario final.
